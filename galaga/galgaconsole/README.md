# Galga Console

Terminal-based Galaga-style game for Kali.

## Controls
- Left Arrow: move left
- Right Arrow: move right
- Space: shoot
- Esc or `P`: pause/unpause
- Q: quit

## Install
```bash
cd <CLONELOC>/TAME/galaga/galgaconsole
./install.sh
```

## Run
```bash
cd <CLONELOC>/TAME/galaga/galgaconsole
./run.sh
```

## Notes
- Requires terminal size at least 45x18.
- Uses Python standard library only (`curses`), so no pip packages are needed.
